# Content review

Every Greek string on the site that is **not** the owner’s own wording, for the owner to approve or edit. The owner’s copy (headline, intro, the nine service titles, the partnership paragraph, the values and the closing line) is used word for word and is not listed. Generated by `npm run content-review` from the source files named in each heading; edit the text there.
